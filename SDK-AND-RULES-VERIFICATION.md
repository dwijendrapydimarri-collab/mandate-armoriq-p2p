# SDK and Hackathon-Rule Verification Checklist

This checklist records what must be confirmed before Mandate is presented as a real ArmorIQ integration. The current folder contains planning material only; no item below should be marked verified without evidence from the SDK, ArmorIQ team, or hackathon organizers.

| Status | Test | Pass condition |
|---|---|---|

| TODO | Parameter scope | Same tool and agent: ₹8,724 allowed; ₹87,240 blocked |

## E. Evidence standard

A claim is **verified** only when it has one of the following: a successful command output committed with the code, an observed SDK response saved in a redacted fixture, an official ArmorIQ document, or written confirmation from the hackathon organizer. A local mock result is useful for development but must be labeled `local adapter` and must not be used as evidence of real ArmorIQ enforcement.
